# 可执行开发计划

## 仓库交付后，先做什么

先在目标 Windows 笔记本运行演示，再启动真实摄像头。设备适用性实验排在完整中文输入和自由鼠标之前；否则很可能在不可用的空间精度上继续堆功能。

以下按一个熟悉 TypeScript/Windows 的开发者估算，只是任务排序与工作量范围，等待试用、设备适配不计入。每阶段达到验收再继续，不用日期替代验收。

| 阶段 | 任务与文件 | 交付物/完成定义 | 估算 |
| --- | --- | --- | --- |

## 任务拆解与明确验收

### A. 视觉 provider

- 定义 `start/stop/onObservation` 生命周期，统一时间戳；停止后旧异步模型结果不回流。
- 记录眼部像素宽度、有效帧、推理耗时、头姿偏移代理；拒绝异常值。
- 相机重开、系统睡眠、视频冻结和分辨率变化使校准失效或进入复检，不继续用旧映射。
- 对照网络输出的 yaw/pitch/方向不能直接塞进屏幕 x/y。写清摄像头坐标约定、归一化和个人映射。
- 验收：同一 target trace 可以比较两个 provider；A/B 结果包含失败条件。

### B. 校准与个体配置

- 数据按位置和试次分组，不随机切帧导致泄漏；不同位置保留数量上限，避免帧率偏重某点。
- 验证区域覆盖边缘和常用输入区；新增重校准而非无限追加未经确认的“伪标签”。
- 档案包含设备标识、分辨率、屏幕缩放、模型版本、参数、日期。默认不含原始脸图。
- 验收：设备/显示设置改变会提示复检；校准失败不激活输入。

### C. 中文 composition

- 键盘事件先进入 composition，不能把每个拼音字母立刻写入系统程序。
- 本地引擎生成候选；Jev 只能在提供的候选里建议预选，不能杜撰字或自动提交。
- 退格先删组合串；组合串为空再删已提交字符；撤销词级提交可恢复组合串。
- 翻页/模式切换使异步建议失效。姓名和常用表达由用户显式加入词库。
- 验收用例：同音多候选、人名、否定句、中英混输、标点、跨页、取消和断网。

### D. 桌面操作

- 首先验证语义目标面板。新增分页、目标名称去重/位置提示；不把同名“确定”当成同一按钮。
- 文字注入绑定前台窗口及捕获的编辑控件；窗口标题只是展示，不能用作唯一身份。
- 对没有 UIA 信息的区域，后续采用放大镜 + 两级定位；这与 OCR/视觉代理是独立路线。
- 任何消息发送、文件删除、账户操作保留具体确认；模型返回 false 不解除确认。
- 验收：所有过期、焦点变化、拒绝权限的情况都清楚反馈，且不重放旧动作。

### E. 发布

- `npm ci`、`npm run assets`、`npm run check`；Windows 上 `npm run dist:win`。
- 安装包签名与患者适用性验证不是当前自动化测试完成的事项。
- 只有真实实机结果加入 `08-validation-status.md` 后，才提高 README 的能力声明。

## 不提前做的工作

不从头训练 gaze foundation model；不接每帧云识别；不把 Jev 当通用生成模型；不同时承诺三个桌面平台；不在没有用户误差数据时精雕密集键盘。这些决定减少最早阶段的无效工作，而不是永久限制产品。
