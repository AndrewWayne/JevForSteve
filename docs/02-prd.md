# PRD：JevForSteve 0.1 → 可试用版本

## 产品目标

让仍具有适用眼部运动能力、手部操作困难的人，能用舒适的动作表达文字、朗读并完成有限的电脑操作。首要价值是表达可靠、可纠错、能休息；其次才是输入速度。

患者是主要使用者；照护者负责初次摄像头定位、配置和故障恢复。不能要求主要使用者在每次校准、休息、网络故障后都用手点一下才能继续。初版仍有照护者依赖，需在验收前逐项减少。

## 典型任务

| 任务 | 完成路径 | 成功定义 |
| --- | --- | --- |
| 表达需求 | 看常用短语 → 预选 → 慢眨眼 → 朗读 | 输出由用户确认的原文 |
| 输入自由文字 | 字母组 → 字母 → 可选词候选 → 修正 → 朗读 | 能删除、保留否定、不被模型自动改写 |
| 休息 | 暂停按钮/长闭眼 → 大恢复目标 | 不继续打字，已写文字保留 |
| 操作程序 | 读取目标窗口 → 按钮面板 → 选择 → 再确认 | 执行对象与所见确认一致 |
| 网络失效 | Jev 弃权/超时 → 继续本地选择 | 基本文字输入不断开 |
| 追踪失效 | 停止提交 → 调整姿势/重校准 | 不将最后一个点反复点击 |

## 范围与状态

| 能力 | 0.1 初版 | 可试用版本要求 |
| --- | --- | --- |
| 悬浮窗 | 可收起；表达/桌面两个模式 | 关键控制有大目标路径、跨会话位置恢复 |
| 摄像头 | 本地 Face Landmarker + 岭回归基线 | A/B 评测、质量门控、漂移检测、设备分级 |
| 校准 | 9 训练点 + 5 验证点 | 随机验证、区域误差图、疲劳中断、断点恢复 |
| 选择 | 主动眨眼、闭眼冻结、去重、长闭眼暂停 | 个体阈值复测、驻留与外接开关后备 |
| 文字 | 英文字母/小词表、六个中文短语、朗读 | 完整中文拼音候选、本地个人词典、撤销 |
| Jev | HTTP 合同与可选语义预选 | 中英分开对照、有收益才默认推荐 |
| 桌面 | Windows 单屏语义按钮面板、有限滚动/文字注入桥 | 实机焦点验证、签名 helper、缩放覆盖 |
| 资料保存 | 会话内保存；不录像、不自动保存文本 | 本地加密/可清除的个体档案与文字恢复策略 |
| 系统 IME | 未实现 | 有需要时另立 TSF/平台适配项目 |

0.1 不是已经完成患者验收的工具。不能把“原型包含摄像头代码”写成“能稳定眼控电脑”。

## 交互原则

1. 窗口默认展开便于首次了解，设置后可收为窄悬浮条。主画面只放当前表达、输入目标、朗读和状态。
2. 工程诊断放在设置及文档；不要把概率、token、模型版本、每帧坐标铺满主界面。
3. 预选变化先让用户看见，再允许确认；闭眼中不移动目标。
4. 表达内容由用户决定。预测候选需要主动选择；没有静默替换、自动发送或“帮你说得更好”。
5. 不把“暂停”和“失去追踪”藏在颜色里，提供文字反馈。不要过度依赖瞬时动画。
6. 常用短语可减少大量眼动，但必须能个性化；0.1 的固定短语是演示集合，后续应允许本人选择。

## 非功能要求与优先级

P0：本地确定性确认、无重复提交、跟踪断开时停止、网络无依赖、目标有效期校验、API key 留在主进程。

P1：CPU 延迟控制、个人配置保存、真中文输入、漂移重校准、低疲劳后备、Windows 实机可靠性。

P2：macOS Accessibility、Linux AT-SPI、多屏、自由光标/放大镜、商业设备适配。Windows 优先是研发范围决定，不表示用户已经指定操作系统；试用设备不同则调整宿主优先级。

## 指标

主指标：错误提交/分钟、完成任务后的修正速度、独立完成比例、主观疲劳、放弃/照护者介入次数。

辅助指标：有效追踪比例、验证点 P50/P90/P95 误差、漂移、意图眨眼漏检、自然眨眼误触、Jev 延迟与弃权率。评测不能只报准确率，也不能只记录容易成功的短句。具体协议见 [评估](05-calibration-and-evaluation.md)。
