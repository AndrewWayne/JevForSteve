# 校准、实验与验收协议

本文所有门槛是**拟定工程标准**。没有把模拟结果或文献数字当作患者结果。

## 1. 每位用户的设置过程

1. 确认姿势舒适，摄像头能同时看到两眼；记录设备、分辨率、显示缩放、戴镜情况。先不用约束头部到不舒适的姿态。
2. 查看追踪是否持续有效。初版没有完整质量面板，应由照护者协助；后续增加眼部有效像素、丢帧率、头姿偏移提示。
3. 显示九点，每点约 2 秒，前 650 ms 作为移视时间不参与拟合；只取睁眼且有效的特征。每点至少 12 帧；不足就等待，不能默认为成功。
4. 标准化特征，用带正则的线性回归分别拟合 x/y。不能用九个单帧，也不能只看训练误差。
5. 显示五个不同位置验证，完全不用于拟合。报告归一化误差与屏幕 DIP 误差；不要称为角度精度或厘米精度，除非测了屏幕尺寸和眼睛距离。
6. 用实际大键布局做随机目标任务，检查一次确认、修正和误触。五点通过也不等于整套 UI 已通过。
7. 自然阅读与主动慢眨眼分别采样；初版各 10 秒仅用于开始调参。正式验证至少自然阅读 5 分钟与 30 次主动动作。
8. 20 分钟后、重新坐姿后重复验证。亮度、屏幕角度、眼镜、摄像头位置发生变化时重新校准。

不能假设 Q/P/A/L/Z/M 是固定注视基准。这些是物理键帽或屏幕键盘的布局，不是跨设备的眼球坐标。校准应建立从眼部观测到屏幕坐标的个人映射。

## 2. 误差与密度

屏幕归一化误差：`sqrt(dx² + dy²)`，两个轴分别按屏幕宽高归一化。屏幕 DIP 误差：`sqrt((dx·W)² + (dy·H)²)`。角度误差需要额外几何信息，不从这两个量直接命名推导。

初版使用 P90 DIP 误差作为启用实验性大键盘的粗门槛，40 DIP 是临时保守上限，不是产品承诺；默认打开分组布局。正式版本应逐布局计算：最小目标半尺寸必须大于误差半径、漂移余量与目标边缘保护之和。大键盘通过不能自动开放小工具栏、密集候选栏或桌面按钮。

必须记录每个验证区域，而不只报一个均值。帧之间高度相关；统计置信区间应按试次或人聚类，不把 30 FPS × 60 秒当成 1800 个独立受试样本。

## 3. A/B 视线实验

| 变量 | 执行安排 |
| --- | --- |
| 模型 | A: 当前特征岭回归；B: OpenVINO 方向模型 + 相同个人屏幕映射预算 |
| 固定项 | 同设备、分辨率、距离记录、相同校准时长、相同目标序列 |
| 条件 | 两种室内照明；初始/重新坐姿；有条件时戴镜与不戴镜分别报告 |
| 任务 | 留出点定位、随机大目标选择、复制短句、自由表达、阅读但不操作 |
| 分段 | 先短轮工程排障，再 20 分钟疲劳/漂移复测；允许随时休息 |
| 顺序 | A/B 交叉顺序，减少熟悉效应 |
| 数据 | 默认匿名事件及坐标；录像仅在另行明确同意的本地研究流程中使用 |
| 退出 | 两种路线在舒适姿势下都无法达到大目标门槛，则测试专用眼动仪适配，不继续让用户反复“练好” |

健康志愿者排障只能证明工程能运行；ALS 用户的运动能力、疲劳、眼睑问题和使用姿势需要个体测试。试用规模先小后大，不将小样本描述为临床有效性证据。

## 4. 眨眼实验

逐事件人工标注自然/主动/长闭眼/不确定。不能把算法自己阈值产生的标签再拿来验证算法。

要测自然眨眼误触次数/分钟、主动眨眼召回率、额外重复尝试、两次提交间隔、长闭眼后误提交。遮挡和摄像头停帧必须作为单独故障测试。初版必须达到“丢帧/过期/revision 变化不产生确认”的确定性条件。

若自然与主动闭眼时长严重重叠，不继续压缩阈值追求速度，改用备用方式。时间阈值不是所有人的通用生理区分器。驻留/外接开关尚在开发计划中，当前不冒充已经支持。

## 5. Jev 对照实验

三组使用完全相同候选事件：G0 几何规则；G1 几何 + 本地词频；G2 G1 + Jev 有限选择。当前仓库词表只有演示规模，G1 的正式词频库仍待接入。

记录正确预选、错误建议、none、用户纠正、延迟 P50/P95、过期率、请求数及实际账单。按中英、普通词、姓名、新词、否定句、无上下文分别报告。冻结 model ID、prompt hash、候选生成版本和实验数据划分。

建议进入默认推荐的条件：在不增加错误提交的前提下，修正后输入速度或必要确认次数至少改善 10%，且参与者认为收益值得网络等待。10% 是产品判断阈值，不是统计显著性的替代。置信区间跨越无改善时继续保留为实验选项。

## 6. 提议的阶段门槛

| 阶段 | 进入下一阶段前要证明 |
| --- | --- |
| 工程逻辑 | 丢帧、重复、过期、UI 变化、非法模型答案测试全部通过 |
| 健康志愿者设备实验 | 大目标任务 ≥95% 一次正确选择；自然阅读误提交 ≤0.1/分钟；持续追踪 ≥90%；按人/设备报告 |
| 个体可试用 | 本人能接受疲劳与纠错成本；有独立暂停与替代输入路径；照护者会恢复；不能仅凭群体均值放行 |
| Windows 桌面 | 100/125/150/200% 缩放；窗口切换、过期、移动控件、只读/密码控件均验证；至少记事本和一个浏览器 |
| Jev 默认推荐 | 配对实验净改善，无静默改写；中文独立通过 |

初版视觉推理性能目标是有效帧 ≥15 FPS、P95 推理到预选延迟 ≤150 ms；先测再优化，不宣称已经达到。

## 7. 离线事件格式与工具

`npm run evaluate -- path/to/events.jsonl` 读取匿名 JSON Lines，输出可复查指标。格式及合成样例在 `fixtures/evaluation.synthetic.jsonl`。每行含 participant（匿名）、session、trial、kind、durationMs，以及相应的 expected/actual、位置误差或 blink 标签。**synthetic 表示人工构造，不能放进真人结果表。**

目前没有从 UI 一键采集真人评测数据的功能。实验员可按协议生成事件文件；下一阶段增加经用户开启的本地记录器。记录器默认不写原文、窗口标题、截图和视频。
